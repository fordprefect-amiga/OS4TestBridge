Readme text (paste into OS4Depot "Readme text" field)

OS4 Test Bridge is a bounded development bridge between Linux and
AmigaOS 4.

This archive contains the native AmigaOS 4 guest component used by that
workflow:
- OS4TestBridge guest agent executable
- payloads for typed/bounded discovery/build/run operations
- guest docs and startup example

Companion components:
- Linux host package: available from the project GitHub release
- VS Code extension: available from the same release (optional; only
  required for VS Code integration workflows)

Bridge model:
- typed and bounded operations (not arbitrary remote shell execution)
- structured request/result handling and diagnostics
- toolchain discovery plus build/run workflow integration

Validated reference environment:
- Linux Mint host
- Kyvos/QEMU Sam460EX
- AmigaOS 4.1
- GCC 11.5 target toolchain

Compatibility notes:
- Expected-compatible: other AmigaOS 4 environments with equivalent
  shared transport, process execution, and suitable SDK/toolchain setup
- Not yet validated: all OS4 hardware/emulator combinations

Installation pointers:
1) Extract OS4TestBridge_OS4_0.1.0.lha on AmigaOS 4.
2) Start with Docs/INSTALL.txt.
3) See Docs/README.txt and Docs/TROUBLESHOOTING.txt.

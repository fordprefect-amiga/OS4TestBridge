OS4 Test Bridge (AmigaOS 4 guest package) — submission draft

Version
0.1.0

Platform requirement
AmigaOS 4.1

Summary
OS4 Test Bridge is a bounded bridge workflow that connects VS Code on Linux to AmigaOS 4 build/run execution.
This package supplies the native AmigaOS 4 guest components required by that workflow.

What this package provides
- OS4TestBridge guest agent executable
- bounded payload set for discovery/build/run/diagnostics
- guest documentation and startup example

Companion requirements
- OS4 Test Bridge Linux host package
- OS4 Test Bridge VS Code extension (.vsix)
- shared transport directories between host and guest

Installation summary
1) Extract `OS4TestBridge_OS4_0.1.0.lha` on AmigaOS 4.
2) Review Docs/INSTALL.txt and configure startup from S/startup-example.
3) On Linux/VS Code: select target configuration, run Check Target, run Inspect Toolchains.
4) Initialize project and use build/run commands from VS Code.

Validated reference environment
- Linux Mint host + Kyvos/QEMU Sam460EX + AmigaOS 4.1

Compatibility notes
- Expected-compatible: other AmigaOS 4 setups with equivalent transport/process/toolchain behavior
- Not yet validated: FlowerPot and other emulator arrangements

Short:
Bounded AmigaOS 4 guest package for OS4 Test Bridge workflows from VS Code.

Long:
OS4 Test Bridge guest package for AmigaOS 4.1. It provides the native guest agent and
payload bundle used by the OS4 Test Bridge system, which coordinates bounded
request/response execution from VS Code on Linux through a Linux host bridge.

Requirements:
- AmigaOS 4.1 or later
- Shared transport directories between AmigaOS guest and Linux host
- OS4 Test Bridge Linux host component required for bridge workflows
- VS Code extension optional and only required for VS Code integration

Archive contents:
- OS4TestBridge executable (guest agent)
- Payloads/ bounded payload bundle
- Docs/INSTALL.txt, Docs/README.txt, Docs/TROUBLESHOOTING.txt
- S/startup-example
- VERSION

Installation summary:
1) Extract `OS4TestBridge_OS4_0.1.0.lha` on AmigaOS 4.
2) Review Docs/INSTALL.txt and Docs/TROUBLESHOOTING.txt.
3) Configure startup using S/startup-example and start the guest agent.
4) On Linux/VS Code, configure target path, run Check Target, then Inspect Toolchains.
